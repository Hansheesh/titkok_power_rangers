# Devpost / Submission Checklist

- [ ] Project overview explains the problem and core thesis.
- [ ] Development tools are listed.
- [ ] APIs used are listed; if none, state that clearly.
- [ ] Libraries/frameworks are listed.
- [ ] Dataset/assets identify the organizer-provided frozen Amazon-derived kit.
- [ ] Setup and installation work from a clean checkout.
- [ ] Steps to reproduce results use the unmodified organizer evaluator.
- [ ] README contains limitations and future improvements.
- [ ] README contains team-member contributions.
- [ ] Experiment log contains reproduced baseline and final metrics.
- [ ] Ablations show which layers actually help.
- [ ] Best configuration is frozen before the final run.
- [ ] Public repository contains no secrets or private evaluator data.
- [ ] Demo shows at least one end-to-end multi-turn recommendation flow.
- [ ] Claims in the pitch match recorded evaluator evidence.
